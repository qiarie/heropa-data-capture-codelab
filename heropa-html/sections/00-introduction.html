Capture and process health data with Kotlin FHIR Data Capture

This guide takes you through the codelab on the Heropa lab, where you write the code in an editor in your browser and the app runs as a web page. You install nothing.

It is built on the published codelab, which was written for Android Studio on your own computer. This guide covers the lab only. If you would rather work in Android Studio, follow the published codelab instead of this guide.

The codelab text comes from the Kotlin FHIR Data Capture project under codelabs directory and is used under the Apache License 2.0.
